Phoenix Blogger Design System
Editorial Style Guide v1.0
Purpose
This document defines optional editorial standards for publications using the Phoenix Blogger Theme. It complements the design system by helping articles deliver a consistent reading experience.

Editorial Philosophy
Every article should teach, inspire, and respect the reader's time. Articles should feel professional, modern, practical, trustworthy, easy to scan, and beautiful to read.
Article Hero
Structure:
• Category (first Blogger label)
• Article Title
• One-sentence summary
• Published Date • Reading Time • Author
• Hero Image

Rules:

- Use the first Blogger label as the category chip.
- Keep titles clear and descriptive.
- Optional 2–3 line summary.
- Hero image spans the content width with rounded corners.
  Categories
  Use Blogger Labels. The first label becomes the article category. Never display a generic 'Article' label if a meaningful category exists.
  Titles
  Write clear, benefit-oriented, descriptive titles. Avoid vague or generic titles.
  Lead Paragraph
  Do not repeat the title, author, or featured image. Begin with a compelling introduction that explains why the reader should continue.
  Typography
  Use H1 for the article title (generated by Phoenix), H2 for major sections, H3 for subsections, followed by paragraphs, quotes, and lists. Maintain a consistent hierarchy.
  Images
  Use one featured hero image and additional images only when they provide value. Apply consistent corner radii and captions where appropriate.
  Pull Quotes
  Highlight memorable insights with consistent quote styling.
  Callout Boxes
  Standardize Tip, Important, Best Practice, and Key Takeaway callouts.
  Technical Content
  Use syntax-highlighted code blocks and explain why examples matter, not only what they do.
  Reading Experience
  Favor short paragraphs, meaningful headings, whitespace, and scannable layouts.
  Article Footer
  Conclude with Key Takeaways, References, Author Card, Related Articles, and Comments.
  Author Card
  Display a consistent author profile including name, role, expertise, and short biography.
  References
  Reference reputable sources and distinguish facts from opinions.
  Editorial Tone
  Helpful, confident, clear, educational, and practical.
  Visual Rhythm
  Hero → Lead → Sections → Images/Quotes/Callouts → Key Takeaways → References → Author → Related Articles → Comments.
  Publishing Rules
  • Never repeat the article title inside the body.
  • Never repeat the author inside the body.
  • Never duplicate the featured image.
  • Use the first Blogger label as the category.
  • Begin with a strong lead paragraph.
  • Keep paragraphs concise.
  • Use headings to guide the reader.
  • End with references, author card, related articles, and comments.
  The Phoenix Test
  Every article should answer YES to:

1. Can readers understand the topic within 10 seconds?
2. Can readers scan the structure within one minute?
3. Will readers learn at least one practical idea they can immediately apply?
