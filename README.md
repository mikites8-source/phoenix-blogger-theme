# Phoenix Blogger Theme

Phoenix is a premium modern Blogger theme rebuilt from the legacy Awesome Inc. template.

## Goals

- Modern UI
- Mobile First
- SEO Optimized
- Dark Mode
- Fast Loading
- Blogger Compatible
- Clean XML
- Material Design Inspired
